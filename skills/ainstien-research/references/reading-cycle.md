# Reading Cycle

Use this guide when the user provides papers, articles, notes, PDFs, web links, or a domain to survey.

## Purpose

Reading is not collection. Reading should build the mental model needed to notice what the field is missing.

The reading log is a thinking scaffold, not a form. Do not interrogate the user field by field. Fill objective fields from the source when possible, then guide the researcher toward the reflective fields that matter for taste, understanding, and idea formation.

## Active Reading Pass

For each source, extract what can be inferred:

- Bibliographic identity: title, authors, year, venue or source
- Problem
- Central claim
- Method or argument
- Evidence
- Key result
- Assumptions
- Limitations
- What the source explains well
- What the source leaves unresolved
- Connections to other sources
- Ideas it creates for the user's project

## Researcher Reflection

Use these as prompts to guide the user over time, not as mandatory questions every session:

- What did you understand from the paper?
- What did you not understand yet?
- Which detail seems important for your project?
- Which assumption or limitation feels fragile?
- What question does this paper raise?
- What possible idea did it spark?
- How does it change the active research state?

Ask only one to three targeted reflection questions when they are useful.

## Memory Summary

After reading, ask the user or produce a short memory-style summary:

- What is the main idea without looking back?
- What changed in the research state?
- What pattern does this source strengthen or weaken?
- What should be read next?

## Reading Saturation

Keep reading while new sources are changing the map. Slow down broad reading when:

- New papers repeat known assumptions.
- Methods and baselines feel familiar.
- The same limitations recur.
- Candidate gaps and claims are forming.
- Search should become targeted rather than broad.

## Source Map

Group sources by function:

- Foundations
- Current state of the art
- Competing explanations
- Methods and tools
- Evaluations and benchmarks
- Negative results or limitations
- Surveys or taxonomies
- Open problems

## Output

Update the research state and, when useful, create or extend a reading log. If the user asks questions or discusses the paper, also use `paper-discussion.md` and update `discussion-notes.md`.
